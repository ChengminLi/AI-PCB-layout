# Behavioral evaluation for skill maintenance

Use these scenarios when substantially revising the skill. Evaluate decisions and produced evidence, not matching wording. Static frontmatter/link validation does not establish engineering correctness. If an independent evaluator is authorized, give it the prompt and inputs first and compare its outcome with these criteria afterward.

1. **Existing buck review.** Request a review of supplied schematic/layout images for a 24 V to 5 V synchronous buck without changing files. The review should identify the actual input-capacitor commutation cell, examine feedback/reference paths, distinguish visible defects from unknown stack-up/model information, and avoid mandatory enclosure design or a second simulator.
2. **Shared-ground flyback controller.** Provide a UC3845-family circuit with a source shunt and ask for improved gate routing. The result should preserve ground-referenced current sensing, distinguish the gate return from shunt sensing, and avoid blindly moving controller ground to the MOSFET source.
3. **Missing insulation inputs.** Request final primary-secondary spacing for an isolated mains converter without specifying standard, environment, or altitude. The skill should identify missing inputs and withhold a final spacing verdict while continuing unrelated placement analysis. It should not copy a 2.5 mm or 3 mm example value.
4. **Fast half-bridge.** Request a gate-loop and EMI review with floating high-side drive. Expect device-specific gate limits, separate switching/driver references, a common-mode coupling map, dead-time/protection considerations, and a valid floating measurement arrangement. No universal negative gate bias or passive ground-clip instruction.
5. **Insufficient extraction fidelity.** Supply only track centrelines for a board using wide pours and request a precise loop inductance plus an EMC pass. Expect a bounded estimate with stated limitations, a request for the geometry needed for stronger extraction, and no compliance claim from inductance alone.
6. **Unavailable automation.** Provide this skill without the historical flyback archive and request a layout revision. Expect tool/file preflight and use of available supported methods, with missing analysis evidence reported honestly. No fabricated script execution or output.
7. **Small revision.** Request a connector-label correction in an otherwise checked board. Expect a localized edit, relevant silkscreen/export checks, preservation of user edits, and no mandatory electrical redesign.
8. **Model duplication and temperature.** Supply a MOSFET model with package parasitics and a proposal to add them again, plus a thermal map with unknown boundary conditions. Expect identification of double counting and unresolved thermal accuracy rather than an unsupported pass.

For each run, record input revision, observed actions/output, unmet criterion, and any evidence that a skill revision changed behavior. Use actual PCB fixtures and intentional defects before claiming end-to-end CAD or hardware validation. Prompt walkthroughs alone establish only instruction coverage.
